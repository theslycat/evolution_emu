# Evolution Emulator

一个基于物理仿真的进化模拟器。实体（Entity）拥有三条由三角函数驱动的腿，在重力场中通过碰撞地面获得推进力，目标是通过进化算法找到能移动最远距离的实体。
**需要注意，本项目部分采用的vibecoding，但核心部分由人类编写。具体说明见后文**
## 原理

### 实体模型

每个实体由以下参数定义：

- **omega (ω)**: 角频率，控制腿部摆动速度
- **theta (θ)**: 相位角，控制腿部初始位置
- **radicals (R)**: 腿长（振幅），受总蛋白质量 (protein=50) 约束

三条腿的端点位置由以下公式计算：

```
x_endpoint = x_body + R * sin(ω * t + θ)
y_endpoint = y_body + R * cos(ω * t + θ)
```

### 物理仿真

- 重力加速度 g = 9.98
- 时间步长 dt = 0.01s
- 碰撞检测：检测实体身体和三个腿端点中 y 坐标最低的点
- 碰撞响应：当最低点触地 (y ≤ 0) 时，给予实体向上的弹跳力和水平推力
- 能量消耗：`E -= R * ω * dt`，能量耗尽则实体停止运动

### 进化算法

1. 生成 N 个随机实体
2. 运行仿真，记录每个实体的最远水平距离
3. 选择移动最远的实体作为"最优个体"
4. 以最优个体的参数 (ω, θ, R) 为中心，使用高斯分布变异生成下一代
5. 重复步骤 2-4

| 文件 | 说明 |
|------|------|
| `main.py` | 核心仿真与进化逻辑（人工手写） |

## 运行

### 进化仿真（纯计算）

```bash
python3 main.py
```

默认运行 1000 个实体 × 1000 代进化，输出每代最优实体的参数和距离。

### 可视化演示

```bash
python3 visualize.py
```

实时动画演示 10 个实体 × 10 轮进化过程：

- 不同颜色代表不同实体
- 金色星号标记当前领先者
- 能量耗尽的实体变暗
- 每轮结束后自动进化并进入下一轮

**依赖**：

```bash
pip install matplotlib
sudo apt install python3-tk   # TkAgg 后端
```

## 参数调整

在 `main.py` 中修改：

- 实体数量 / 进化代数：`range(0, 1000)` 和 `range(1000)`
- 能量上限：`self.energy = 2000`
- 变异标准差：`0.5`（`regen_entity` 调用处）

在 `visualize.py` 中修改：

- `NUM_ENTITIES = 10`：可视化实体数
- `NUM_ROUNDS = 10`：可视化轮数
- `range(5)`：每帧模拟步数（控制动画速度）
